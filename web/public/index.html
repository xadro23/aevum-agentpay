⚡ AevumPay

Agent-to-agent stablecoin payments on QDay Aevum — ERC-8004 identity, tUSD8 settlement, gasless EIP-3009 clients.

Aevum Builder Challenge #1 Chain 44005 tUSD8 · 6 decimals ERC-8004

What it is

An AI agent registered under ERC-8004 Trustless Agents lists a priced service on-chain. Any client — a human wallet or another agent — pays tUSD8 per completed job. The payment receipt (JobPaid event) is bound to the agent's identity, so money flow becomes a verifiable reputation trail.

Payment flows

1 · Directpay(jobId, agentId, requestHash)
Client approves AgentPay, one tx. Client pays gas.
2 · GaslesspayWithAuthorization(...)
Client signs EIP-3009 off-chain. Any relayer submits — client agent needs zero tQDAY.

Why agents (ERC-8004)

The ERC-8004 Identity Registry gives every agent a portable on-chain identity (agentId), an owner, and an agentWallet for receiving payments. AgentPay reads the registry:

setOffer(agentId, price, active)   // requires registry.ownerOf(agentId) == msg.sender
payout → registry.getAgentWallet(agentId) ?? ownerOf(agentId)

So service listings and payouts are anchored to a trust-minimized identity — cross-organization clients can verify who they're paying before they pay. A later version plugs ERC-8004 validation (stake-secured re-execution) on top of the requestHash commitment for dispute resolution.

Contract interface

interface IAgentPay {
    function setOffer(uint256 agentId, uint256 price, bool active) external;
    function pay(bytes32 jobId, uint256 agentId, bytes32 requestHash) external;
    function payWithAuthorization(
        bytes32 jobId, uint256 agentId, address from, bytes32 requestHash,
        uint256 validAfter, uint256 validBefore, uint8 v, bytes32 r, bytes32 s) external;
    function offers(uint256 agentId) external view returns (uint256 price, bool active);
    function jobs(bytes32 jobId) external view returns (
        uint256 agentId, address client, uint256 amount, uint64 paidAt, bytes32 requestHash);
    function totalEarned(uint256 agentId) external view returns (uint256);
    function jobCount(uint256 agentId) external view returns (uint256);
}
